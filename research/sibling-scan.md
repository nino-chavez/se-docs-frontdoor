## Findings

1. **`SIBLING_NO_ARTIFACT_LINK` — BLOCKING.** `research/current-state/workspace-prior-art.md:22`, `:24`, `:26` cite `~/Workspace/dev/archive/knowledge-index` and its audit artifact `src/mcp-server.ts`. Neither exists: `Read` on the file returns "File does not exist," and `Read` on `~/Workspace/dev/archive` returns "File does not exist" where `~/Workspace/dev/ref` returns `EISDIR` — the parent directory is gone, not merely the file. Ruled out an ignore-rule artifact: `~/.config/git/ignore` contains only `**/.claude/settings.local.json` and `.worktrees/`. Same broken citation at `research/sources/definition-and-grill-2026-07-09.md:28` and `research/prior-art/README.md:17`.
   **This is workspace drift, not research degradation** — the 2026-07-09 run recorded these paths as verified, and `archive/` has since been removed. Route the fix accordingly.
   **Material consequence, not a path nit:** ADR-0001 trigger 3 names knowledge-index as the contingent crawl+index architecture. That contingency currently points at a reference implementation that is no longer in the workspace, so the fallback has no reference to build from.
   **Remediation:** locate the project (git remote, or another machine) and repoint all four citation sites, or restate the indexing contingency as having no surviving internal reference and downgrade it to an external/vendor reference. Per gate rules this scan does not hunt for the new location.

2. **`SCAN_INCOMPLETE` — capture-side sibling missed** (scanner-surfaced; not one of the spec's four enumerated codes, so treat the code as this scan's judgment, though finding 1 already carries the block). `tools/claude-docs-toolkit/` is absent from both passes — including `capture-domain-prior-art.md:54-57` § "Adjacent, weaker relevance," which names `specchain` and `local-dictation` but not a tool whose stated purpose is autonomous documentation generation with a coverage-audit and gap-detection skill. The gap is not decorative: Phase 0 census and the sponsor's diagnosis deliverable are the two pieces of scope with **zero** prior-art coverage anywhere in the corpus, and this is the workspace instance of both.
   **Remediation:** add it to `research/prior-art/capture-domain-prior-art.md` with a decision-level read of `docs/research/autonomous-knowledge-synthesis.md` and an explicit divergence. The likely divergence, stated so the research can confirm or reject it: the toolkit generates docs *from code in the repo*, which cannot recover knowledge that was never in code — precisely P7. The SE corpus documents a platform built by someone else.

3. **`SCAN_INCOMPLETE` — secondary census sibling missed.** `tools/fleet-observability/` (and its absorbed predecessor `tools/repo-health-check/`) are absent from both passes. Add at least a named-and-scoped entry so a future scan does not treat "periodic sweep → scorecard → findings.json" as unexplored. Lower priority than finding 2.

4. **Root cause of findings 2 and 3 — the capture primitive is a category description, not a searchable primitive.** `research/prior-art/capture-domain-prior-art.md:3` scopes to "tooling and patterns that record knowledge *at the point of work*." Compare the retrieval primitive at `workspace-prior-art.md:5`, which is grep-able. A loose primitive is why a tool literally named *autonomous documentation generation* did not surface. Not filed as `PRIMITIVE_UNSPECIFIED` — the section does name a primitive, and it is far more specific than the spec's failing examples — but the remediation for findings 2 and 3 must include tightening it to searchable terms (e.g. "documentation-coverage audit over an unschema'd multi-author corpus" and "derive-from-byproduct capture with no authoring step").

5. **Note (non-blocking) — header will fail an automated re-run.** `research/prior-art/capture-domain-prior-art.md` carries no header matching this gate's grep set; its title is `# Prior art — the capture domain (domain E)`. This scan passes Check 1 on substance, since a dedicated file with a scan date, a scope line, and per-sibling structure is maximally delineated. But since the verdict is already BLOCK and the operator gets one remediation pass, add the literal string `## Prior Art (Workspace)` (or `## Sibling-Project Scan`) as an H2 above section 1 so a re-run does not block a second time on a header.

6. **No `DIVERGENCE_UNJUSTIFIED`.** All six cited siblings state a constraint difference, not a silent preference — zero-code primary path, uniform ACLs favoring federation, official MCP servers already existing, P3 blocking an ingester layer, single-operator curation judgment, git-native substrate vs external systems. This is the strongest dimension of both passes.

7. **Absence declarations verified.** The Slack surface is declared greenfield (`workspace-prior-art.md:36-38`), and the two unreachable capture sources — the sponsor's "ask commerce"/CLA (BD-3) and whatever delivery/IPM uses to record project state — are declared unscanned-and-unreachable (`capture-domain-prior-art.md:59-66`).
